The page, before you print it

Choose an image and say how large it should come out. The preview shows the whole sheet: the image at that size in real millimetres, the line to cut along, and the rulers that tell you whether the printer kept to the scale.

  1. Choose an image — click the field, drop a file on it, or paste one.
  2. Type a width or a height in mm or cm; the other side follows the image.
  3. Print at 100%, measure a ruler, cut along the red line.

Nothing is stored — the image is held only for as long as the request takes.

Calibrate a printer

Print any page at 100% / "Actual size" and measure both rulers with a steel ruler, from the 0 to the 100 mark, as precisely as you can. Then say what each measured.

Leave the left ruler empty if the print only has the bottom one; the same correction is then used both ways.
